# My Build-in-Public Story

*A short, honest post about building my portfolio and agent with AI.*

Ten weeks ago, I didn't have public proof of my Machine Learning work. Today, I am launching my live portfolio featuring a functional, autonomous AI research agent. 

Building this with an AI assistant completely changed my workflow. The biggest win? I used AI to write the Python integration for the ArXiv API in minutes. I could never have written that integration from scratch so quickly; AI handled the boilerplate XML parsing, which freed me up to focus entirely on the core logic of the data pipeline.

But it wasn't magic, and things definitely broke. When we built the contact form, I realized it allowed completely blank, empty spam submissions. The AI didn't catch it—I had to step in, debug the data flow, and manually enforce HTML validation rules to fix the form. 

AI didn't build this portfolio for me. It acted as my junior developer, clearing the brush so I could actually build the tool I wanted. Proof is better than claims. You can check it out live here: `https://rohindth-08.github.io/FlyRank-_Internship_ML-/`
